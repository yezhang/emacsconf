#+title: Doom Emacs 配置导读
#+author: 整理自 Doom 官方模板注释
#+startup: overview

这份文件是 =~/.config/doom/= 三个配置文件中官方模板注释的中文导读，
原始英文示例全部保留。日常配置请直接改对应的配置文件，本文档仅供查阅学习。

* 配置文件结构

Doom 的用户配置都在 =doom-user-dir= （本机为 =~/.config/doom/= ）下，三个核心文件：

| 文件         | 作用                                             | 修改后          |
|--------------+--------------------------------------------------+-----------------|
| =init.el=    | 启用/停用 Doom 模块（modules），控制加载顺序     | 需 =doom sync=  |
| =packages.el= | 声明额外安装的包                                 | 需 =doom sync=  |
| =config.el=  | 具体配置逻辑，大部分内容写这里                   | 直接重启/reload |

日常修改流程：

#+begin_src sh
# 改了 init.el 或 packages.el 后
doom sync

# 检查环境问题（缺外部依赖等）
doom doctor

# 升级 Doom 本身及所有包
doom upgrade
#+end_src

Emacs 内改完 =config.el= 不想重启：=SPC h r r= （=doom/reload=）。

* packages.el：声明要安装的包

** 从 MELPA / ELPA / emacsmirror 安装

#+begin_src emacs-lisp
(package! some-package)
#+end_src

** 直接从 git 仓库安装

#+begin_src emacs-lisp
(package! another-package
  :recipe (:host github :repo "username/repo"))
#+end_src

仓库根目录没有 =PACKAGENAME.el= 、或文件在子目录时，用 =:files= 指定：

#+begin_src emacs-lisp
(package! this-package
  :recipe (:host github :repo "username/repo"
           :files ("some-file.el" "src/lisp/*.el")))
#+end_src

完整 recipe 格式见 https://github.com/radian-software/straight.el#the-recipe-format

** 禁用 Doom 自带的包

#+begin_src emacs-lisp
(package! builtin-package :disable t)
#+end_src

** 覆盖自带包的 recipe

只需给出要改的部分，其余继承 Doom/MELPA 的默认 recipe：

#+begin_src emacs-lisp
(package! builtin-package :recipe (:nonrecursive t))
(package! builtin-package-2 :recipe (:repo "myfork/package"))
#+end_src

** 指定分支 / 锁定版本

默认分支不是 =master= 的包必须显式指定分支（straight.el 的限制，
见 radian-software/straight.el#279）：

#+begin_src emacs-lisp
(package! builtin-package :recipe (:branch "develop"))

;; 锁定到某个 commit
(package! builtin-package :pin "1a2b3c4d5e")
#+end_src

** 解除版本锁定

Doom 会把包固定（pin）到特定 commit，随版本更新。=unpin!= 可解除：

#+begin_src emacs-lisp
(unpin! pinned-package)
(unpin! pinned-package another-pinned-package)
(unpin! t)  ; 全部解锁（不推荐，容易坏）
#+end_src

* config.el：配置逻辑

** 核心原则：用 after! 包裹

重新配置一个包时，务必包在 =after!= 块里，否则 Doom 的默认值会覆盖你的设置：

#+begin_src emacs-lisp
(after! PACKAGE
  (setq x y))
#+end_src

例外情况（可以直接顶层 setq）：

- 文件/目录类变量（如 =org-directory= ）
- 文档明确要求"加载前设置"的变量（用 =C-h v VARIABLE= 查文档确认）
- =doom-= 开头或 =+= 开头的 Doom 变量

** 常用宏速查

| 宏              | 用途                                     |
|-----------------+------------------------------------------|
| =use-package!=  | 配置一个包（Doom 对 use-package 的封装） |
| =after!=        | 某包加载后再执行配置                     |
| =map!=          | 绑定快捷键                               |
| =load!=         | 加载本目录下的其他 =*.el= 文件           |
| =add-load-path!= | 把本目录下的路径加入 =load-path=         |

** 字体配置

Doom 提供五个字体变量：

| 变量                      | 用途                             |
|---------------------------+----------------------------------|
| =doom-font=               | 主字体                           |
| =doom-variable-pitch-font= | 比例字体（org 正文等）           |
| =doom-big-font=           | =doom-big-font-mode= 演示用大字  |
| =doom-symbol-font=        | 符号                             |
| =doom-serif-font=         | =fixed-pitch-serif= 的衬线字体   |

示例：

#+begin_src emacs-lisp
(setq doom-font (font-spec :family "Fira Code" :size 12 :weight 'semi-light)
      doom-variable-pitch-font (font-spec :family "Fira Sans" :size 13))
#+end_src

字体问题排查：

- =M-x describe-font= 查看当前字体
- =M-x doom/reload-font= 刷新字体设置
- 找不到字体基本都是字体没装好，很少是 Doom 的问题

** 其他常见顶层设置

#+begin_src emacs-lisp
;; 主题
(setq doom-theme 'doom-one)

;; 行号：t 普通行号，'relative 相对行号，nil 关闭
(setq display-line-numbers-type t)

;; 身份信息（GPG、邮件、文件模板等会用）
(setq user-full-name "John Doe"
      user-mail-address "john@doe.com")
#+end_src

* init.el：模块管理

=(doom! ...)= 块按分类列出所有模块，取消注释即启用，注释掉即停用。
模块名后的 =+flag= 是功能开关，如：

#+begin_src emacs-lisp
(org +dragndrop +roam)    ; org 模块 + 拖拽附件 + org-roam 支持
(corfu +orderless)        ; corfu 补全 + orderless 模糊匹配
(evil +everywhere)        ; evil 模式全局启用
#+end_src

查看模块文档：光标移到模块名（或 flag）上按 =K= ；按 =gd= 直接跳到模块源码目录。

注意：=init.el= 在最早阶段加载，*不要* 在这里用 =use-package!= / =after!= ，
也不要执行耗时或易出错的代码——每次运行 =doom= CLI 命令时它都会被求值。

* org-babel 的特别注意

*不要* 用 =org-babel-do-load-languages= 手动注册语言——Doom 已经把这个
函数覆盖为空操作（no-op），写了也不生效。

Doom 的机制是按需懒加载：执行 =#+begin_src LANG= 代码块时，自动
=(require 'ob-LANG)= 。所以只要 =ob-xxx= 包装好了（=packages.el= 声明过），
就能直接用，无需任何额外配置。

个别语言名和库名不一致的例外（如 rust → rustic-babel）由 Doom 内置的
=+org-babel-mode-alist= 处理。

* 常见错误（官方提醒）

- *急切加载包* ：config.el 里直接 =(require 'foo)= 会拖慢启动，优先用 =use-package!= 延迟加载
- *手动管理包* ：不要绕过 packages.el 直接装包，doom sync 会清理掉
- *滥用 org-babel-do-load-languages* ：见上一节，Doom 里不需要
- *全局 delete-trailing-whitespace*：可能破坏某些文件格式，用 =ws-butler= 或按需开启

* 内置文档入口

| 操作                     | 作用                                |
|--------------------------+-------------------------------------|
| =SPC h d h= / =C-h d h=    | Doom 文档索引（含模块列表）         |
| =K= （光标在符号上）       | 查看该函数/变量/模块的文档          |
| =gd= / =C-c c d=           | 跳转到符号定义（模块则是源码目录）  |
| =C-h o=                  | 查看任意符号的完整文档              |
| =~/.config/emacs/docs/=   | 本地完整官方文档                    |
